# Score Sync / 曲谱同步

方便曲谱同步一条龙制作的 Rust GPUI 工具.

从扫描谱或 PDF 出发, 在同一界面完成 **谱表分块 → 蒙版清理 → 加底色裁切 → 视频剪辑导出**, 支持工程保存/继续编辑, 一路做到可以直接发布的同步曲谱视频 (MP4/MKV).

当前版本: **1.2.7**

## 功能

| 面板 | 作用 |
|------|------|
| **分块** | 自动识别大谱表行, 跨页组合, 导出竖向拼接切片; 输出组合支持 Ctrl 多选与整块拖拽调序 |
| **蒙版** | 在组合拼合图上框选/折线/画笔蒙版 (浮动取色器: HSV / RGB / 滴管取色), 遮挡不想出现的记号 |
| **工程** | 打开/保存 `.staffcrop` 工程包; 内嵌「谱面加底色」批量处理, 也可一键把底色作为可撤销的底层异步应用/取消到工程内的输出组合; 页图落会话 tmp、内存仅保留当前页±4; 视频终稿缓存于旁路 `.staffcrop.cache` |
| **视频** | 剪辑软件式的视频/淡入淡出/音频三轨编辑器: 把「输出组合」拖入视频轨道、导入多段音频依次播放、标记淡入淡出黑场; 三轨边界彼此靠近时自动吸附, 一键导出 MP4/MKV |

分块与蒙版之间会同步当前组合选中, 并自动滚动到对应列表/标签位置.

## 环境

- Windows (当前以 Windows + GPUI 为主)
- Rust stable (`cargo` / `rustc`)
- 运行时依赖 `pdfium.dll` (PDF 打开) 与 `ffmpeg.exe` (视频导出), 二者都不
  随源码提交: 优先找程序自身同目录下的那份, 找不到再退回系统 PATH. 本地
  开发把两者放进 `vendor/` (已 gitignore) 再拷到 `target/debug(或release)/`
  即可; 打包发行版时随 exe 一起放进同一目录/压缩包.

## 构建与运行

```bash
cd score_sync
cargo run -r
```

日常迭代可用较快的 `release` (已关 LTO); 正式发包可用:

```bash
cargo build --profile release-max
```

也可传入初始文件:

```bash
cargo run -r -- path\to\page.png path\to\score.pdf
cargo run -r -- path\to\project.staffcrop
```

发布构建产物: `target/release/score_sync.exe` 或 `target/release-max/score_sync.exe`.

## 工程格式

- 扩展名: `.staffcrop` (zip)
- 内含 `project.json`、`pages/*.png`; 底色启用时另有底色图片
- 页图像素在会话期间备份于系统临时目录; 内存仅保留当前页前后各 4 页
- 视频素材终稿缓存在工程旁 `{名}.staffcrop.cache/` (不打进 zip; 退出保留; 工程面板可「清除视频缓存」)
- `project.json` 里也保存了工程底色的启用状态, 以及「视频」面板的完整时间轴
  (视频/淡入淡出/音频片段、播放头位置), 下次打开工程会原样恢复; 音频文件本身
  不重新打包进工程, 需保持原路径有效才能继续回放/导出
- 快捷键: `Ctrl+S` 保存, `Ctrl+Shift+S` 另存, `Ctrl+Shift+O` 打开, `Ctrl+Shift+N` 新建工程 (各面板通用)
- 打开/保存工程都是异步执行, 不会卡住界面; 有未保存改动时关窗会确认; 标题栏 `*` / 保存中转圈
- 启动时若未指定命令行参数, 会自动重新打开上次保存/打开过的工程 (记在
  `%APPDATA%` 里, 与底色路径记忆同一套机制)

## 仓库结构

```
score_sync/           # 主程序 (本仓库根)
  src/                # 分块 / 工程 / 检测 / GUI
  assets/             # 图标
  vendor/             # ffmpeg.exe / pdfium.dll (不提交, 见上"环境")
  crates/
    mask_tool/        # 蒙版库 (可嵌入)
    apply_bg/         # 谱面加底色库 (可嵌入)
    score_video/      # 视频栏库 (可嵌入)
```

## 常用快捷键

应用内按 `H` / `F1` 可查看完整说明. 概要:

- `Ctrl+O` 打开图片/PDF
- `D` / `A` 识别本页 / 全部页
- `Ctrl+A` 全选本页原子块 · `M` 合并选中块 · `E` 导出组合
- 右侧切到蒙版后: 框选/折线/画笔, `Ctrl+A` 全选蒙版, `Ctrl+Z`/`Y` 撤重; 色块取色器支持 RGB 与滴管
- 右侧切到视频后: 空格播放/暂停, `←`/`→` 快退快进, `N` 插入下一张组合,
  `I`/`O` 标记淡入/淡出, 轨道区 `Ctrl+滚轮` 缩放
