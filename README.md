# Score Sync / 曲谱同步

方便曲谱同步一条龙制作的 Rust GPUI 工具.

从扫描谱或 PDF 出发, 在同一界面完成 **谱表分块 → 蒙版清理 → 加底色裁切 → 视频剪辑导出**, 支持工程保存/继续编辑, 一路做到可以直接发布的同步曲谱视频 (MP4/MKV).

当前版本: **1.8.12**

## 功能

| 面板 | 作用 |
|------|------|
| **分块** | 自动识别谱表行 (先认五线, 相邻谱表须墨迹像素直接 8 连通才收成一行; 贴边、无孔或过窄连通域不计), 跨页组合, 导出竖向拼接切片; 输出组合支持 Ctrl 多选与整块拖拽调序; `Ctrl+M` 把本页未组合块两两配对; `P` 组织页面 (缩略图网格排序/删除/复制粘贴). 以路径和文字为主的 PDF 按矢量导入, 用长水平谱线收谱行; 扫描图铺满、几乎没有路径的页仍光栅 |
| **底色** | 左侧预览底色+组合 (只读, 滚轮切换组合, 可取色); 右侧面板选择底色图或纯色并应用/取消到工程组合 (二者互斥, 底色图保留会话缓存, Ctrl+Z/Y 可撤应用、取消、等比填充、设为分辨率、纯色和目标分辨率). 工程页面就是目标分辨率, 谱面宽对齐这一页, 更高时才缩小装进页高. 选图按文件内容认格式; 比目标小的图在应用时按「等比填充」放大. 「批量加底色」弹窗比例与工程分开, 高度足够时按谱面宽度、上下补边, 高度不足时按谱面高度、左右补边. 标题栏图标新建/打开/保存 `.staffcrop`; 页图落会话 tmp、内存为按视口缩小的预览代理 (高清页收窄窗口; 放大时按窗口裁切原图); 超高清底色原图落磁盘、内存只留一页工作拷贝; 视频终稿缓存于旁路 `.staffcrop.cache` |
| **蒙版** | 在组合拼合图上拖动/裁切「组合分块」 (四边拖裁; Shift+拖可左右挪, 可超出原块左右, 探出原块左右的部分只在本界面画出, 终稿按原块左右截掉); 辅助线对齐谱表 (单组用大括号尖, 一块多组用整块几何中心); 框选/折线/画笔蒙版 (浮动取色器: HSV / RGB / 滴管取色), 遮挡不想出现的记号. 选中分块后 `T` 进入修图: 位图页做位图修图 (滤镜, 调整, 画笔不透明度; 点在画布上复制选区, 点在图层面板上复制图层), 矢量页做矢量修图 (路径, 节点, 填充与描边, 组合; 应用后按当次分辨率光栅). 应用后写入工程 `edits/`. 修图改条带高度时, 完全在这块下方的遮盖跟着平移, 压在这块上的遮盖留在原位. 分块再改这条的上下沿后, 拼合和导出改用当前裁切, 修图文件留着并在列表标「脱离」, 改回原范围后自动重新套用 |
| **视频** | 剪辑软件式的视频/转场/音频三轨编辑器: 把「输出组合」拖入视频轨道、导入多段音频依次播放、标记淡入淡出、刷入或交叠翻页; 三轨边界彼此靠近时自动吸附, 一键导出 MP4/MKV |

分块与蒙版之间会同步当前组合选中, 并自动滚动到对应列表/标签位置.

## 环境

- Windows / macOS (macOS 包由 GitHub Actions 编译; 本地无 Mac 也可发版)
- Rust stable (`cargo` / `rustc`)
- 运行时依赖 pdfium (`pdfium.dll` / `libpdfium.dylib`) 与 ffmpeg
  (`ffmpeg.exe` / `ffmpeg`), 二者都不随源码提交: 优先找程序自身同目录下的那份,
  找不到再退回系统 PATH. 本地开发把它们放进 `vendor/` (已 gitignore) 再拷到
  `target/debug(或release)/` 即可; 打包发行版时随可执行文件一起放进同一目录/压缩包.
  底色面板用的底色图, 以及备用的 ffmpeg / pdfium, 见
  [sidecars](https://github.com/IvolliousElectrolux/score-sync/releases/tag/sidecars)
  (GitHub 附件名不能用中文, 底色文件为 `background.png`, 可改名为 `底色.png`).
  各平台安装包已带对应的 ffmpeg 与 pdfium, 一般不用再下.
  裁剪版 ffmpeg 的能力清单见下节 (写视频/音频功能时对照这个, 不要假定完整 ffmpeg).

## 裁剪版 ffmpeg

配方是 `scripts/build_ffmpeg.sh` (configure 列表是唯一准绳), Actions 是
`.github/workflows/ffmpeg.yml`. 成品挂在
[sidecars](https://github.com/IvolliousElectrolux/score-sync/releases/tag/sidecars):
`ffmpeg-windows-x64.exe` (windows-2025 + MSVC, 无 msys dll) /
`ffmpeg-macos-arm64` / `ffmpeg-macos-x64` /
`ffmpeg-linux-x64` / `ffmpeg-linux-arm64`. 不要在开发机上编.
macOS 成品不 UPX (Gatekeeper); Windows / Linux 会 UPX.
主程序 MIT, sidecar 因 `libx264` 为 GPL, 只当外部进程调用; 发行目录带
`ffmpeg-COPYING.txt`.

写新功能时: 先看自己要不要 sidecar 里已经有的东西; 没有就改脚本里的
`ENCODERS` / `DECODERS` / `MUXERS` / `FILTERS` / 协议再跑 ffmpeg workflow,
不要去调用系统 PATH 上那份完整 ffmpeg 来"先能跑". 画面转场继续在 Rust 里按帧画,
不要指望 `xfade` / `overlay` / `fade`.

**程序实际在用的:**

| 场景 | sidecar 做什么 |
|------|----------------|
| 导出画面 | stdin `rawvideo` RGBA (`-i -`, 协议必须有 `fd`) → `-vf format=yuv420p` → `libx264` (yuv420p, CRF, preset=medium, tune=stillimage) |
| 导出音频 | MP4: `aac`; MKV: `flac`. 多段: `filter_complex` 里 `atrim` / `asetpts` / `aformat` / `apad` / `concat`. 无音轨: `lavfi` `anullsrc` |
| 预览解码 | m4a/aac/mp4/mov 转临时 WAV `pcm_s16le`; 其它非 16-bit WAV (mp3/flac/ogg 等) 走 ffmpeg 管道 `-f wav` |
| 预览倍速 | `-af atempo` (单级 0.5–2, 3x 拆成两级) 后同样 `-f wav` 喂 rodio; 导出仍是 1x |
| 最终封装 | 视频+音频 stream copy 进 mp4/mkv |

**编进去了 (脚本里的列表, 摘常用项):**

- 编码: `libx264`, `aac`, `flac`, `pcm_s16le`
- 解码: `aac` / HE-AAC / `alac` / `mp3` / `flac` / `vorbis` / `opus` / `speex` / 多种 PCM 与 wav-ADPCM / `rawvideo`. **没有视频解码器** (含 h264)
- 解复用: `rawvideo`, `lavfi`, `mov` (mp4/m4a/m4b), `mp3`, `aac`, `flac`, `ogg`, `wav`, `w64`, `aiff`, `matroska`
- 复用: `mp4`, `mov`, `ipod`, `matroska`, `wav`, `pcm_s16le` (CLI `-f s16le`), `flac`, `null`, `adts`
- 滤镜: `format`, `scale`, `aformat`, `aresample`, `atrim`, `setpts`, `asetpts`, `apad`, `concat`, `atempo`, `anull`, `anullsrc` 以及 buffer 类
- 协议: `file`, `pipe`, `fd` (FFmpeg 7.1 把 `-i -` 当成 `fd`, 缺了 stdin 编码会 `Protocol not found`)
- 设备: `lavfi` indev (静音轨)

**不要假定能做 (常见踩坑):**

- 抽自己导出的 mp4 帧 / 解码别人的视频: 没有 h264 decoder, 也没有 `ffprobe`
- 写出 jpg/png: 没有这些图像编码器
- 视频转场、烧字、叠图: 没有 `xfade` / `overlay` / `fade` / `drawtext`
- 网络流: `--disable-network`
- 缩放补边导出: 已改成 Rust `fit_pad`, 滤镜里虽留了 `scale` 但导出路径不再用它拼静帧

## 构建与运行

```bash
cd score_sync
cargo run -r
```

日常迭代可用较快的 `release` (已关 LTO); 正式发包可用:

```bash
cargo build --profile release-max
# Windows 本体再压一刀: upx --best --lzma target/release-max/score_sync.exe
```

也可传入初始文件:

```bash
cargo run -r -- path\to\page.png path\to\score.pdf
cargo run -r -- path\to\project.staffcrop
```

发布构建产物: `target/release/score_sync.exe` (Windows) 或 `target/release/score_sync` (macOS).
GitHub Actions 工作流 `.github/workflows/macos.yml` 在打 `v*` 标签或手动
`workflow_dispatch` 时于 macos-14 上编译 arm64 与 x64 (x64 交叉编译, 不再等
macos-13), 并上传 `score_sync-<ver>-macos-arm64.zip` / `macos-x64.zip`.
时间轴对齐小工具只在 v1.3.10 发过, 之后不再随版附带.

## 工程格式

- 扩展名: `.staffcrop` (zip)
- 内含 `project.json`、位图页的 `pages/*.png`; 底色启用时另有底色图片. 矢量页不写整页 PNG, 改为内嵌 `pdfs/*.pdf` (`project.json` 里该页 `coord` 为 `pt`, 区域坐标是 point). 只含位图页的工程仍可被 1.5 打开; 含矢量页的需要 1.6.0. 修过的分块另有 `edits/{分块 id}/`: 位图修图是图层和 `flat.png`; 矢量修图是 `manifest.json`, `images/` 和 `preview.png`, 拼合按当次分辨率光栅, 不读 `flat.png`. 没有 `kind` 的旧修图按位图. 覆盖只在页和上下沿仍与烘焙时一致时取代裁切; 没有记下路径的底色图按位图保留, 纯色只认 RGB
- 页图像素在会话期间备份于系统临时目录; 内存窗口默认当前页前后各 4 页 (高清页自动收窄), 只留按视口缩小的预览代理, 识别/导出再临时解码原图
- 视频素材终稿缓存在工程旁 `{名}.staffcrop.cache/` (不打进 zip; 退出保留; 切到视频面板时只保留当前组合, 旧组 PNG 会删掉)
- `project.json` 里也保存了工程底色的启用状态, 以及「视频」面板的完整时间轴
  (视频/淡入淡出/音频片段、播放头位置), 下次打开工程会原样恢复
- 音频不打进工程 (wav 等往往很大), 只记原路径、时长与切割点; 文件搬走后谱面切片
  和淡入淡出不会坏, 但预览没声、导出在合成音频时失败. 放回原路径即可; 路径变了
  则先删音频轨上的旧片段再导入, 不要叠在旧片段后面
- 快捷键默认是 `Ctrl+S` 保存, `Ctrl+Shift+S` 另存, `Ctrl+Shift+O` 打开工程, `Ctrl+Shift+N` 新建工程, `Ctrl+,` 打开设置 (标题栏图标, 各面板通用). 可在设置里改, 并选择菜单上是否显示键位
- 打开/保存工程都是异步执行, 不会卡住界面; 有未保存改动时关窗会确认; 标题栏 `*` / 保存中转圈
-   启动时若未指定命令行参数, 且设置里开着「打开时恢复上次工程」, 会自动重新打开上次保存/打开过的工程 (记在
  用户配置目录, Windows 为 `%APPDATA%\score_sync`, 与配色, 语言, 快捷键同一份 `config.json`)

## 仓库结构

```
score_sync/           # 主程序 (本仓库根, Cargo workspace)
  src/                # 分块 / 工程 / 检测 / GUI
  assets/             # 图标
  vendor/             # ffmpeg.exe / pdfium.dll (不提交, 见上"环境")
  crates/
    mask_tool/        # 蒙版库 (可嵌入, 可独立运行)
    photo_edit/       # 分块修图 (可嵌入, 可独立运行; 宿主里位图页按 T)
    vector_edit/      # 矢量分块修图 (可嵌入, 可独立运行; 宿主里矢量页按 T)
    apply_bg/         # 谱面加底色库 (可嵌入, 可独立批处理; 批量用 frame_size, 工程页面即目标分辨率)
    score_video/      # 视频栏库 (可嵌入, 可独立调试)
  tools/
    warp_staffcrop_timeline.py  # 旧工程时间轴 t' = a*t + b (无参数打开窗口)
```

## 常用快捷键

应用内按 `H` / `F1` 可查看完整说明. 下面是默认键位, 可在标题栏齿轮里改 (Windows 的 Ctrl 在 macOS 为 ⌘, Alt 为 ⌥):

- `Ctrl+O` 打开图片/PDF (仅分块面板; 蒙版/底色/视频不响应)
- `D` / `A` 识别本页 / 全部页
- `Ctrl+A` 全选本页原子块 · `M` 合并选中块 · `Ctrl+M` 本页未组合块两两配对 (奇数剩一块则并入下页第一块) · `E` 导出组合
- 双页对开: 悬停两页之间出现竖线, 点一下选中这一节 (一对中间的书脊一直显示, 也可以点选). 选中节后, 「复制」和粘贴插在这两页中间; 没选节时仍紧贴在最后点中页的右侧. `Ctrl+C` 记住选中页, `Ctrl+V` 贴到选中的节, 否则贴到当时选中页的右侧. 右键可粘贴到这一页的左侧或右侧, 或在前面/后面插入空白页
- 谱表分块的「组织页面」同样可以点两页之间的节, 把复制内容插在中间; 没选节时仍贴到当时选中页的右侧. 右键可复制, 或粘贴到这一页的左侧或右侧. 副本带着页内已经做好的分块, 蒙版, 微调和修图. 某一块还和没被复制的页组合在一起时, 这一块单独成组, 不把另一页的块拖进来
- 右侧切到底色后: 左侧预览组合 (滚轮切换); 「选择底色」导入图, 「应用/取消底色」与「使用/取消纯色底色」互斥; 「设为分辨率」用导入图的宽高, 「等比填充」把较短边对齐目标分辨率; 调色盘 HSV / RGB / 滴管可从左侧预览取谱纸色; `Ctrl+Z` / `Y` 撤回底色操作
- 右侧切到蒙版后: 默认选择态可直接拖块 (上下; 四边裁切; Shift+拖左右, 可超出原块左右, 终稿仍按原块左右截掉); `T` 修当前分块 (位图或矢量, Ctrl+S 仍是保存工程); `B` 框选 / `L` 折线 / 画笔, `Ctrl+A` 全选蒙版, `Ctrl+Z`/`Y` 撤重; 顶栏「辅助线」「对齐」; 色块取色器支持 RGB 与滴管
- 分块与蒙版: `Ctrl+←` / `Ctrl+↑` 上一页, `Ctrl+→` / `Ctrl+↓` 下一页 (macOS 为 `⌘`); 画布上 `Ctrl+Shift+滚轮` 同样 (macOS 为 `⌘⇧`, 向上上一页). 蒙版换的是组合页签
- 位图修图: 画笔调色盘可调不透明度, 滴管连透明度一起取. 点在画布上 `Ctrl+C` / `V` 复制粘贴选区; 点在图层面板上复制粘贴图层
- 矢量修图: 选择 `V`, 节点 `A`, 画布 `K`, 手形 `H` 或空格, 钢笔 `P`, 铅笔 `B`, 橡皮 `E`, 套索 `L`. `Ctrl+G` 组合, `Ctrl+Shift+G` 取消组合, `Ctrl+Alt+G` 重新组合 (macOS 为 ⌘⌥G). 方向键微调, Shift 一步为 10. 帮助仍用 `F1` 或标题栏 `?`
- 右侧切到视频后: 空格播放/暂停, `←`/`→` 快退快进, `N` 插入下一张组合,
  `W` 刷入下一张 (切页并附 1 秒左→右转场), `X` 交叠下一张 (切页并附 1 秒叠化), `I`/`O` 标记淡入/淡出, 轨道区 `Ctrl+滚轮` 缩放; 预览按素材自身比例装进 16:9, 不拉扁

## 版本摘要

### 1.8.12
- 视频: 转场轴增加「交叠」 (上一页溶进下一页, 钉在翻页边界, 默认 1 秒); `X` 在播放头切到下一张并附上该转场, 不能与淡入淡出叠置

### 1.8.11
- 组织页面和双页对开: 悬停两页之间出现竖线, 点一下选中这一节. 对开一对中间的书脊一直显示, 也可以点选. 选中节后, 复制和粘贴插在这两页中间
- 拖动排序时, 指针离开页面、停在两页之间, 节的高亮仍然亮着, 松手就落在这一节上

### 1.8.10
- Mac 上拖动分块页签, 以及组织页面里拖动页面, 一帧只处理一次鼠标移动. 按住不动时不再每隔一小段就重画
- 组织页面页数多时只排可见的几行缩略图. 落点是盖在格子上的竖线, 拖动时格子不再重新排开
- 松开鼠标完成页签或页面调序时, 不再在界面线程里解码旁边几页的原图. 缺的页在后台补
- Ctrl+Z 先撤回刚刚做的那一步. 撤回页序时沿用内存里已有的页图, 当前页画面不重新解码, 拖动页签后撤回会把页面顺序一起还原
- 复制或粘贴页面时, 新页沿用内存里已有的页图, 不再在界面线程里把整页原图再拷一份并解码. 画面没换就不重做贴图
- 双页对开拖动时, 落点没变不再重画, 页数多时只排可见的几行. 松开调序或删除页面时, 不再在界面线程里解码旁边几页, 当前页画面没换就不重做贴图

### 1.8.9
- 设置里的快捷键页可以搜索. 输入名称, 命令 id 或分组, 也可以输入键位, 如 Ctrl+S, cmd+s, 空格
- 「录键」直接按下要找的快捷键. Esc 退出录键, 点进搜索框则改回打字
- 冲突时仍是列表上方的红字, 不会把冲突的键写进去

### 1.8.8
- 视频里按 N 翻页, 切点落在按下那一瞬间的声音上. 接下来两张谱会提前备好, 按下就能换画面; 这一张还没解码完时先留着上一页
- 按住 N 或 W 只切一次页. 系统连发不再接着切, 也不再弹出「间隔过近」
- FLAC, mp3 等不能按采样点跳的格式, 解码改到单独的线程, 出声不再堵在解码管道上. 16-bit WAV 仍按采样点跳转

### 1.8.7
- 多段 mp3 / flac / m4a 从头播放时, 计时和播放条与声音一起走. 以前会先出声大约 1 秒, 计时才开始; 按这个慢钟标的切点, 导出的画面就整段偏早
- 播放中拖进度条不再把界面卡住: 拖动时停声并停住计时, 松开后从松开的位置继续
- 暂停后再播, 声音、计时和进度条从同一位置继续, 不再先从更早的地方出声
